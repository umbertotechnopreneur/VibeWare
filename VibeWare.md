# VibeWare

This project collects the VibeWare brand assets and the logo decision. The term was coined on **5 October 2026**. Umberto selected proposal **02 Floppy**: a denim-blue pixel-art floppy disk, a cream label with a VW monogram, and the VibeWare wordmark.

![Selected VibeWare logo](Branding/vibeware-logo.png)

## Approved direction

1980s computing, lo-fi and pixel art. The brief explicitly excludes neon art. Keep the selected artwork unchanged; the other seven concepts remain archived proposals, not approved alternatives.

## Software context

The current software context is the portable Photo Organizer in `E:\Ai-Toolbox`, whose About window identifies the code as VibeWare. VibeWare is a brand/code label, not a software license or a guarantee of AI output quality.

This project archives the artwork and records the selection. The current Photo Organizer About window includes the approved VibeWare logo and a link to the planned manifesto URL. That URL was not live at the last recorded verification.
