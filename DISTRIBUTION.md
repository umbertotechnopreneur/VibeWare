# Distribution

## Repository distribution

This public repository distributes VibeWare documentation, press-kit artwork and the proposed source-header text. It does not distribute an ESP32 Luna Shell release, a compiled Photo Organizer package, AI models, private logs or user data.

The VibeWare repository is intended to remain small and source-oriented:

- `Branding/` contains the selected reference artwork.
- `press-kit/` contains press-ready PNG and GIF assets.
- `Archive/` preserves earlier logo concepts and their provenance.
- `docs/` contains reusable source-header guidance.

## Asset notes

The generated PNGs and GIF are raster artwork. “High resolution” in this kit does not mean SVG or a source-vector file. Preserve file names and checksums where provenance is required. See [ASSET-NOTICES.md](ASSET-NOTICES.md).
