# Amiga boot motion reference

## What it is

Local reference file: `external/Amiga_1200_boot_loading_startup_screen_with_floppy_sound.mp4`.

It is a 6.15-second, 320x240 H.264 MP4 supplied for the VibeWare project on 5 October 2026. The visible imagery includes Commodore-Amiga copyright text and a MakeAGIF watermark.

## How it is used

It is cited in the press kit only for the motion of a floppy moving into a slot. No boot animation derived from this reference is currently included in the VibeWare press kit.
